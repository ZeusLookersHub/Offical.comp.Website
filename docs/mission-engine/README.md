# Lookers AI — Mission Engine (المرحلة الأولى)

ده قلب الأداة: من أول ما المستخدم يختار المهمة من الكواكب، لحد ما يأكد البريف.
الكود في `core/mission-engine/`، والاختبارات في `tests/mission-engine.test.ts` (`npm run test:mission-engine`).

## المبدأ

- **القواعد هي اللي بتقرر.** هي اللي تحدد السؤال الجاي، وإمتى نقف، وإيه اللي اتأكد.
- **الموديل (في المرحلة التانية على السيرفر) دوره ٣ حاجات بس:** يستخرج المعلومات، ويكتب الناتج، ويراجعه.
- **مفيش دليل = مفيش معلومة.** أي قيمة بتتسحب من كلام المستخدم لازم يكون معاها الجملة اللي قالها. وأسماء البراند والكلام الحرفي لازم يكونوا موجودين في كلامه **بالحرف**.
- **أقل أسئلة ممكنة.** الخانات ليها ٣ مستويات:
  - `critical`: بنسأل عليها دايماً.
  - `important`: بنسأل عليها في حدود عدد الأسئلة المسموح (`questionBudget`)، وبعد كده نستخدم القيمة الافتراضية.
  - `nice`: ما بنسألش عليها خالص. القيمة الافتراضية بتظهر في البريف، والمستخدم يقدر يعدلها.
- **الافتراضات مكشوفة.** كل قيمة افتراضية بتظهر في البريف ومعاها السبب.

## المسار

```
nextStep → intake (الفكرة) → submitIntake → question … answer/skip → brief → confirmBrief
→ buildComposeRequest (للسيرفر) → runGates على الناتج → repairInstruction لو في فشل
```

- **التعديل بعد التأكيد:** `answer` بيعدل خانة واحدة، ويرجّع البريف لحالة "محتاج تأكيد".
- **الاقتراحات الحيّة:** `suggest(blueprint, slotId, typed, session)` بتطلع chips فورية وانت بتكتب. ولما السيرفر يدخل، هيزود عليها أفكار من الموديل.

## الـ Blueprint

بيانات بس، من غير كود. ده عشان نقدر بعدين ننقله لقاعدة البيانات، ونعمل له إصدارات. كل Blueprint فيه:
- سؤال الفكرة، وأمثلة البداية (starters).
- الخانات (slots) بأسئلتها وشرحها ومثالها.
- الاختيارات، والكلمات اللي بتختارها تلقائياً.
- القيم الافتراضية بشروطها، والمفردات بتاعة الاقتراحات.
- عقد الناتج (output contract).
- بوابات الجودة (gates).
- الأدوات المستهدفة.
- تعليمات الكتابة للموديل.

أول Blueprint كامل هو `product-photo`. بيسأل من صفر لـ ٤ أسئلة بعد الفكرة. والبوابات بتمسك:
- اسم البراند لو اتغير (حالة DAVIDOFF ← DAVIE DOVE).
- الكلام الحرفي لو اتغير.
- المقاس لو غلط.
- إعدادات الأداة لو دخلت في وصف المشهد.
- أي كلام متألف على الصورة.
- البرومبت لو مش بالإنجليزي.

## اللي لسه

- **المرحلة التانية:** Edge Function جديدة اسمها `lookers-ai-engine`، فيها الاستخراج بالموديل والتوليد حسب العقد والفحص والإصلاح. وجداول للجلسات والبريفات والنتائج. الـ function الحالية `lookers-ai-generate` مش هتتلمس.
- توصيل الشات الحالي بالمحرك ده للمهمات اللي ليها Blueprint.
- Blueprints للتجربة: فيديو منتج، عرض استثماري، صفحة هبوط، حملة.
